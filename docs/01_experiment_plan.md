# 1. Experiment plan

**Objective.** Turn real Enron e-mails into synthetic e-mails that read as if written at *another* company (other people, organisations, industry, country, currency, dates) with no identifying trace of the source, while keeping what downstream LLM fine-tuning learns from: the e-mail's *form* (headers, greeting/sign-off, wrapping, quoted history), *style* (terse, informal) and *label-bearing content* (intent, privilege/legal cues, sensitivity, sentiment). Consilio's tasks are review-style classification, so structure and labels matter more than prose polish.

**Research** (from prior knowledge; no systematic search was run). (i) Replacing identifiers with realistic surrogates beats `[NAME]` redaction for utility and hides residual misses (Carrell et al. 2013). (ii) Regex + spaCy NER / Presidio + Faker are precise on clean text but weak on noisy mail. (iii) LLMs transfer semantics well but memorise (Carlini et al. 2021), and Enron is in The Pile, so an LLM can re-introduce real names → a rewrite step needs an independent verifier. (iv) Train-on-synthetic/test-on-real is the utility gold standard (out of time-box; I use label-preservation agreement), real-vs-synthetic detectability for realism, and a cross-family LLM judge (Zheng et al. 2023).

**Methodology.** Hybrid pipeline: *deterministic de-identification* → *constrained LLM domain transfer* (sees only pseudonymised text) → *verify-and-repair* → render as raw e-mail. Ablation on 120 stratified e-mails (folder × has-quoted-history): **rule-based only**, **naive LLM-only**, **hybrid** (+ a v1→v2 iteration, four generator LLMs). Metrics from separate signals: *privacy* (independent leak checks incl. full names of any Enron person; verbatim 8-gram copying), *fidelity* (length, structure agreement, KS), *realism* (LLM judge; blinded "which is real?"), *utility* (original-vs-synthetic label agreement, Cohen's κ). Success = low leakage, high fidelity/label preservation, detectability well below the baselines, < US$0.005/e-mail.
